# LAKSAMANA - Aplikasi Data Sains
Pendekatan hibrida: KNN (klasifikasi kerentanan iklim) + Linear Regression (estimasi defisit dan buffer stock). Studi kasus Kota Tanjungpinang.
## Menjalankan
    pip install -r requirements.txt
    streamlit run app.py
Pastikan `Dataset_Pangan_Iklim_Cleaned_Normalized.xlsx` berada satu folder dengan `app.py`.
